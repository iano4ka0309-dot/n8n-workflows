# Sales Funnel Audit & Data Enrichment (course homework)

Case study for a fictional B2B SaaS company, **CloudTools** (document-flow automation). All data is fictional and comes from the course assignment.

**Status:** work in progress. Sections are filled in as each part is completed.

## Parts

1. **Sales process audit**: funnel conversion and losses per stage, the biggest bottleneck, an AI solution for it.
2. **CRM data analysis**: field completeness, the most critical gap, data enrichment sources.
3. **Data enrichment system**: a discovery call script and an AI prompt that analyses a client profile.
4. **RFM analysis**: RFM scores for 10 clients, segments and recommended actions.

## Notes

- No credentials, client data, or private document links are stored here.
